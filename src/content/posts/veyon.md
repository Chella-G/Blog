## Veyon Free and Open Source(Foss) Application

This is one of the best free and open source(Foss) application for the educational purpose. It is used for the remote monitoring and control of many computers.

## To Download the Software

```
https://veyon.io/download/
```

<img src="/assets/Choose_Os_with_arc.png" alt="Choose Os" style="max-width:100%;"/>

> ***Before install understand there is concept like master, client think the master as a teacher and client as the student.***


> ***Now install the software and open veyon configurator in the Master System and Select for all the first options, go to authentication create a key pair it will create the public and private key, export and keep the private key with yourself only and copy the public key to a pendrive or shared folder on the network for future use.***
